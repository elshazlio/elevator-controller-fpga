================================================================================
                         OPERATION INSTRUCTIONS
================================================================================

1. POWER ON
   ├─ HEX0 displays "0" (ground floor)
   ├─ All LEDs are OFF
   └─ All switches should be in DOWN position

2. RESET SYSTEM
   ├─ Press KEY[0] button
   ├─ Elevator returns to floor 0
   └─ All internal states cleared

3. REQUEST A FLOOR
   ├─ Flip switch SW[N] to UP position (where N = desired floor 0-9)
   ├─ Elevator starts moving:
   │  ├─ If N > current floor: LEDR[0] turns ON (moving up)
   │  ├─ If N < current floor: LEDR[1] turns ON (moving down)
   │  └─ If N = current floor: LEDR[2] turns ON immediately (door opens)
   ├─ HEX0 counts up/down showing current floor
   ├─ Each floor takes approximately 2 seconds
   └─ Upon reaching floor N:
      ├─ Movement LED (LEDR[0] or LEDR[1]) turns OFF
      ├─ LEDR[2] (door_open) turns ON
      ├─ Door stays open for ~2 seconds
      └─ LEDR[2] turns OFF (ready for next request)

4. MULTIPLE REQUESTS
   ├─ Flip multiple switches UP simultaneously
   ├─ Elevator services them in priority order:
   │  ├─ If moving UP: visits higher floors first (ascending order)
   │  └─ If moving DOWN: visits lower floors first (descending order)
   └─ Flip each switch DOWN after its floor is reached

5. TIMING
   ├─ Floor-to-floor movement: ~2 seconds
   ├─ Door open duration: ~2 seconds
   └─ Example: Floor 0 → Floor 9 = 9 floors × 2 sec = ~18 seconds

================================================================================
                        TROUBLESHOOTING GUIDE
================================================================================

SYMPTOM: HEX0 shows nothing
   → Check that ssd_hex[6:0] pins are correctly assigned
   → Verify ssd.sv module is included in project
   → Check that HEX0 is working (test with simple pattern)

SYMPTOM: HEX0 shows wrong numbers
   → Verify pin order: ssd_hex[0]=A, [1]=B, [2]=C, [3]=D, [4]=E, [5]=F, [6]=G
   → Check if segments are inverted (active-high vs active-low)
   → Review ssd.sv logic

SYMPTOM: No LED response to switch inputs
   → Verify SW[9:0] pin assignments match inside_buttons[9:0]
   → Check that switches are in correct positions (UP = request)
   → Press KEY[0] to reset system

SYMPTOM: LEDs stuck ON or behaving erratically
   → Press KEY[0] to reset
   → Turn all switches to DOWN position
   → Check for pin assignment conflicts in Pin Planner

SYMPTOM: Elevator moves too fast or too slow
   → Verify CLK_FREQ parameter = 50_000_000 in elevator_top_fpga.sv
   → Check that CLOCK_50 is connected to PIN_M9
   → Timing should be ~2 seconds per floor

SYMPTOM: Programming fails
   → Verify USB Blaster is connected and recognized
   → Check "Hardware Setup" in Programmer shows USB-Blaster
   → Try power cycling the board
   → Reinstall USB Blaster drivers if needed
